# CLI Reference

## Usage

```bash
orchid <COMMAND>
```

## Commands

### `version`

Print version information.

```bash
orchid version
```

### `web`

Start the web UI server.

```bash
orchid web
```

### `workspace`

Open the TUI workspace dashboard.

```bash
orchid workspace
```

### `agent`

Run an individual agent.

```bash
orchid agent git-summarizer
orchid agent content-drafter
```

### `flow`

Execute an end-to-end workflow pipeline.

```bash
orchid flow dev-to-content
```
