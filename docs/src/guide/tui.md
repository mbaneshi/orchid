# TUI Dashboard

## Starting the TUI

```bash
orchid workspace
```

## Controls

| Key   | Action          |
|-------|-----------------|
| `q`   | Quit            |
| `j/k` | Navigate up/down |
| `Tab` | Switch panels    |

## Architecture

The TUI is built on:

- **Ratatui** — terminal rendering framework
- **Crossterm** — cross-platform terminal backend
